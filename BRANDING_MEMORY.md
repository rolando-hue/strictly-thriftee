# Strictly_Thriftee Brand & Asset Memory

## Core Brand Identity
* **Business Name:** `Strictly_Thriftee`
* **Typography Layout:** `Strictly_` stacked above `Thriftee`
* **Official Slogan:** *"Never retail, always a sale!"*
* **Core Palette:**
  * Top lettering (`Strictly_`): Warm cream (`#FFEFCE`)
  * Bottom lettering (`Thriftee`): Vibrant orange (`#FF6A00`)
  * Outer outline / drop shadow: Deep forest green (`#002613`)
* **Core Motifs:** Chunky retro rounded lettering, hanging thrift price tag with string, 4-point sparkle stars, decorative underline banner.
